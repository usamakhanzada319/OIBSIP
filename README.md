# Web-L1-LandingPage

This is Task 1 of my Oasis Infobyte internship – a static landing page built with HTML and CSS.

---

## Project Overview

A modern, responsive service landing page for Creative Studio, a digital agency brand.  
This project demonstrates foundational HTML and CSS layout skills with a focus on clean code, consistent styling, and mobile-first responsiveness.

---

## Features

- Fixed and sticky navigation bar with smooth scrolling
- Hero section with headline, subheadline, and call-to-action button
- Services section featuring Web Design, UI/UX, Branding, and SEO
- Testimonials section with client feedback cards
- Footer with quick links and social media icons
- Fully responsive across mobile, tablet, and desktop devices
- Clean typography with distinct heading and body font sizes
- Consistent color palette applied throughout all sections

---

## Tech Stack

| HTML5 | Structure and semantic markup
| CSS3 | Styling, layout, and responsiveness using Flexbox and Grid
| Font Awesome | Social media icons
| Google Fonts (Inter) | Clean and modern typography
